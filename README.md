# 万物起卦

心里想一件事，拿手机对着眼前的东西一扫。

手机在本地认出画面里的东西、数清楚，按《梅花易数》的"物数占"起一卦：被数到的东西化成金粒，落成上卦；十二时辰盘转停，落下下卦；动爻烧红翻转，得出变卦，最后盖一方朱印。整场大约 14 秒，结束后可以直接存成短视频。

## 怎么起的卦

《梅花易数·物数占》原文：

> 凡見有可數之物，即以此數起作上卦，以時數配作下卦。即以卦數並時數總除六取動爻。

- 上卦：数到几个，除以 8 取余数（余 0 作 8），按先天数定卦：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。
- 下卦：当下时辰数（子一……亥十二），除以 8 取余数。
- 动爻：物数加时辰数，除以 6 取余数（余 0 作上爻）。

不少现代教程把下卦算成"物数加时辰数"，这是照"声音占"类推的。本项目默认从原文，改 `src/core/meihua.js` 里的 `COUNT_LOWER_RULE` 一个常量就能切换。

眼前没数到东西时，改用《梅花易数》的年月日时起卦（农历年支数 + 月 + 日为上卦，再加时辰为下卦）。时辰按手机本地时间，子时（23 点起）算作次日。

每一步的算法都会写在屏幕下方，解读页里也有，懂行的人可以自己核对。

## 隐私

识别模型（EfficientDet-Lite0，约 4.6 MB）和运行时都放在自己的站点下，画面只在手机里处理，不上传。

## 本地运行

```bash
npm install
npm run dev
```

打开终端里显示的地址。相机需要 HTTPS 或 localhost；在手机上调试可以用 `npx vite --host` 加一个本地证书。

没有相机也能看效果：在网址后面加 `?demo`（示意图，两只鸟），可以再加 `&hour=15` 固定时辰、`&n=3` 改数量。

```bash
npm test                          # 起卦算法、农历、数字等单元测试
node scripts/build-zhouyi.mjs     # 重新生成周易数据（含校勘）
node scripts/font-chars.mjs && python3 scripts/build-fonts.py   # 重新裁字体
```

## 部署

`npm run build` 生成 `dist/`，是纯静态文件，放到任何静态托管都行。所有资源都是同源的，不依赖谷歌、jsDelivr 等在国内不稳定的域名。

## 技术

three.js 单画布渲染整场仪式（照片化墨、墨潮、粒子、毛笔爻画、先天六十四卦圆图、时辰盘、书法字与朱印），后期叠加辉光、冲击波、震屏、色散。声音全部用 Web Audio 现场合成（大鼓、编钟、石磬、古琴拨弦、风声）。整个项目没有一张图片、一段音频文件。

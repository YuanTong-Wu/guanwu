# 万物起卦

心有一事，见物而占。

拿手机对着眼前的东西一扫。手机在本地认出画面里的东西、数清楚，按《梅花易数》的"物数占"起一卦。

整场约十七秒，大动作少而准：

1. 定格，一声磬。一滴墨落下，从落点把整个画面晕成水墨。
2. 其余褪成留白，只剩被数到的东西——杯子、萝卜、一只猫，都成了一幅写意小品。
3. 纸收成一张册页，题款"见杯三 · 申时"。
4. 黑底上白墨一笔写一爻。六爻写完，一声钟，静一秒。
5. 朱笔圈出动爻，停一停，爻变。写下"夬之大壮"。
6. 印章"砰"地落在册页上，几片金箔飘下。

结束后可以存成短视频，也可以看卦辞：原文在前，白话在后。

## 怎么起的卦

《梅花易数·物数占》原文：

> 凡見有可數之物，即以此數起作上卦，以時數配作下卦。即以卦數並時數總除六取動爻。

- 上卦：数到几个，除以 8 取余数（余 0 作 8），按先天数定卦：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。
- 下卦：当下时辰数（子一……亥十二），除以 8 取余数。
- 动爻：物数加时辰数，除以 6 取余数（余 0 作上爻）。

不少现代教程把下卦算成"物数加时辰数"，这是照"声音占"类推的。本项目默认从原文，改 `src/core/meihua.js` 里的 `COUNT_LOWER_RULE` 一个常量就能切换。

眼前没数到东西时，改用《梅花易数》的年月日时起卦（农历年支数 + 月 + 日为上卦，再加时辰为下卦）。时辰按手机本地时间，子时（23 点起）算作次日。

每一步的算法都会写在屏幕下方，解读页里也有，懂行的人可以自己核对。

## 隐私

识别模型（EfficientDet-Lite0，约 4.6 MB）和运行时都放在自己的站点下，画面只在手机里处理，不上传。

## 本地运行

```bash
npm install
npm run dev
```

打开终端里显示的地址。相机需要 HTTPS 或 localhost；在手机上调试可以用 `npx vite --host` 加一个本地证书。

没有相机也能看效果：在网址后面加 `?demo`（示意图，两只鸟），可以再加 `&hour=15` 固定时辰、`&n=3` 改数量；`&img=/_test/某张照片.jpg` 用真照片走完整流程（真识别、真入画）；测试照片放在 `.test-assets/`（不进仓库，也不进构建产物）。

检查画面的两个开发工具：

- `?demo&img=…&snaps=1.2,4.5,9` 把这些时刻的画面存到 `.snaps/`；`&snapfps=30&snapto=17` 连续截帧，可用 ffmpeg 合成预览视频。
- `node scripts/e2e.mjs .fake/cam.y4m`：用本机 Chrome 加假摄像头走一遍"起卦 → 取景 → 仪式 → 卦辞"，截图并报告页面错误。假摄像头视频可以用 ffmpeg 从任意照片生成（见脚本开头）。

```bash
npm test                          # 起卦算法、农历、数字等单元测试
node scripts/build-zhouyi.mjs     # 重新生成周易数据（含校勘）
node scripts/font-chars.mjs && python3 scripts/build-fonts.py   # 重新裁字体
```

## 在自己手机上玩

手机和电脑连同一个 Wi-Fi：

```bash
npm run phone
```

它会构建并用自签名证书开一个 HTTPS 地址（终端里 Network 那一行，如 `https://192.168.1.5:4443`）。手机浏览器只在 HTTPS 下才给网页用相机，所以打开时会有一次证书警告：iPhone Safari 点"显示详细信息 → 访问此网站"，安卓 Chrome 点"高级 → 继续前往"。

想用 4G 或在微信里试，可以再开一个临时公网链接（装了 cloudflared 的话）：

```bash
cloudflared tunnel --url https://localhost:4443 --no-tls-verify
```

拿到链接的人都能打开；关掉命令链接就失效。整个应用在访客手机上运行，不耗任何额度，只用电脑的上传流量（每位新访客首次约 16 MB）。

## 部署

`npm run build` 生成 `dist/`，是纯静态文件，放到任何静态托管都行。所有资源都是同源的，不依赖谷歌、jsDelivr 等在国内不稳定的域名。

## 技术

three.js 单画布渲染整场仪式：定格时用一个着色器把照片"画"成水墨存进贴图（大块浓淡墨加勾线和飞白），之后每帧只读这张贴图；毛笔爻画、朱笔圈、书法字、朱印、金箔都是运行时用 Canvas 画出来的纹理。首页是邵雍"先天六十四卦圆图"做的细线转盘，在平面与立体之间缓缓往复。声音全部用 Web Audio 现场合成（石磬、墨滴、笔擦纸、编钟、盖印、木鱼）。整个项目没有一张图片、一段音频文件。

识别用 MediaPipe 0.10.35 + EfficientDet-Lite0（int8，CPU）。固定这个版本是因为 1.x 起内置了无法关闭的遥测；页面还加了只许同源连接的 CSP。
